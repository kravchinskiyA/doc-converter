# 6. Движки конвертации, OCR и антивирус (converters-ocr.md)

## Стек движков обработки
- **Антивирус:** ClamAV (`clamd` + `FreshClam`).
- **Изображения:** Sharp / libvips.
- **Генерация PDF:** `pdf-lib`.
- **Рендеринг PDF и миниатюры:** PDFium.
- **DOCX → PDF:** LibreOffice (headless-режим).
- **PDF → DOCX и OCR:** PaddleOCR / PP-StructureV3 (локальный изолированный Python-процесс).

## Обязательная антивирусная проверка (ClamAV)
- **Строгое правило:** Ни один файл не передается в генераторы превью, миниатюры, OCR или конвертеры до получения успешного вердикта антивирусного сканера ClamAV.
- При обнаружении угрозы или сбое проверки файл немедленно отбрасывается, задача получает ошибку, а файл удаляется с диска.

## Спецификации конвертации

### 1. Изображения → PDF (JPG, PNG, WEBP)
- Поддерживаются `.jpg`, `.jpeg`, `.png`, `.webp` (статический; анимированный WEBP отклоняется).
- Формирование отдельных PDF либо объединение набора в один файл (чекбокс «Объединить изображения в один PDF»).
- **Формат листа:** Стандарт A4, поля строго **10 мм** со всех сторон.
- **Ориентация:** Автоматическая для каждого листа (горизонтальное изображение -> альбомная ориентация; вертикальное/квадратное -> книжная).
- **Масштабирование:** Центрирование с сохранением пропорций без обрезки и растягивания.
- **Прозрачность:** В PNG и WEBP прозрачные области заменяются **белым фоном**.

### 2. PDF → Изображения (JPG, WEBP)
- Одностраничный PDF конвертируется сразу; многостраничный предоставляет выбор страниц по сгенерированным миниатюрам.
- Параметры растрирования: 72, 150 или 300 DPI (по умолчанию 150 DPI).
- Качество сжатия: шкала 1–100 (по умолчанию 85).
- Выходное расширение для JPG сохраняется строго как `.jpg`.

### 3. Документы
- **DOCX → PDF:** Выполняется через LibreOffice headless с изоляцией профиля пользователя.
- **PDF → DOCX:** Выполняется через локальный Python-процесс PaddleOCR/PP-StructureV3 для распознавания структуры и текста. Защищенные паролем PDF отклоняются без попыток взлома.

## Ограничения ресурсов на задачу
- Максимальное время обработки одной задачи: 10 минут.
- Максимальный объем оперативной памяти на задачу: до 2 ГБ (включая дочерние процессы).
