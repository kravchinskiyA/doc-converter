# Дизайн-система и UI стандарты: Augen Pro (design-system.md)

Данный документ фиксирует визуальный код, правила верстки интерфейса, цветовую палитру, типографику и ограничения дизайна для веб-приложения `apps/web`.

---

## 1. Концепция и философия

Стиль **Augen Pro** — клинически-белый минимализм («Apple keynote on surgical white»), ощущение невесомости, монохромный фон с единственным электрическим акцентом (Signal Blue). Интерфейс воспринимается как высокотехнологичный инструментальный прибор: ультратонкие начертания (weight 350), плавающие pill-элементы, глубокий «воздух» (вертикальные отступы 90+px) и полное отсутствие декоративных теней.

---

## 2. Цветовая палитра

| Название | HEX | Назначение и ограничения |
| :--- | :--- | :--- |
| **Off-Black** | `#0f1012` | Основной текст, темные плашки (футер), заливки иконок на светлом фоне. Не чисто черный, с едва заметным холодным оттенком. |
| **Pure Black** | `#020201` | Вторичный текст, контуры иконок, акцентный контраст на белых поверхностях. |
| **Off-White** | `#f2f2f4` | Фоновый холст страницы (Canvas), подложки секций — фирменный светлый фон. |
| **Pure White** | `#fdfdfd` | Поверхности карточек, инпутов, плавающих панелей. Контраст создается за счет смены тона, а не теней. |
| **Steel Gray** | `#5e5e5e` | Вторичный приглушенный текст, подписи, неактивные лейблы (соответствует стандарту доступности AA 6.4:1). |
| **Ash Gray** | `#8f8f8f` | Текст отключенных элементов, вспомогательный текст низкого приоритета. |
| **Signal Blue** | `#0071e3` | **Единственный хроматический акцент:** контуры тегов, разделители, рамки фокуса, интерактивный цвет ссылок. **Категорически запрещено использовать как сплошную фоновую заливку для CTA-кнопок!** |

## 3. Типографика

- **Основной шрифт:** `PP Neue Montreal` (альтернативы в порядке приоритета: `Inter` с начертаниями 300/400, `Söhne` или `General Sans`).
- **Базовое начертание:** Вес **350 (Book)** используется практически для всех текстовых элементов — от заголовков (27px) до основного текста (16px). Иерархия строится исключительно за счет размера шрифта, а не за счет жирности.
- **Вторичное начертание:** Вес **400 (Regular)** допустим только для компактных подписей кнопок и иконок. Запрещено использовать `bold` / `semibold` (> 400).
- **Межстрочный интервал (Line-height):** 1.20.
- **Трекинг (Letter-spacing):** Единый `-0.02em` для всех размеров текста — создает плотную, инженерную типографику.

### Шкала размеров:
- **Caption:** `10px` / line-height `12px` / letter-spacing `-0.2px`
- **Body:** `16px` / line-height `19.2px` / letter-spacing `-0.32px`
- **Subheading:** `18px` / line-height `21.6px` / letter-spacing `-0.36px`
- **Heading:** `27px` / line-height `32.4px` / letter-spacing `-0.54px`

---

## 4. Сетка, отступы и скругления (Border Radius)

- **Максимальная ширина контента:** `max-w-[1200px]` с центрированием по горизонтали.
- **Вертикальные отступы между секциями:** `90px` – `100px` (просторный ритм).
- **Внутренние отступы карточек (Padding):** `69px` (на десктопе).
- **Базовый шаг между микроэлементами:** `6px`.

### Радиусы скругления:
- **Кнопки (Buttons):** `26px`
- **Навигационные плашки (Nav pills):** `10px`
- **Большие контентные карточки (Cards):** `54px` (мягкий силуэт)
- **Теги, чипы, бейджи и ссылки (Tags & Pills):** `9999px` (полный pill-shape)
- **Контейнеры секций:** `63px`
- **Тонкие рамки:** `0.5px` – `1.8px` (hairline)

## 5. Компоненты и паттерны интерфейса

1. **Floating Pill Navigation Bar:**
   - Плавающая панель с отступом сверху ~34px, фон `#fdfdfd`, скругление `10px`, горизонтальный паддинг `11px`. Не растягивается на всю ширину.
2. **Ghost Link Button:**
   - Без фона и рамки, цвет `#0f1012`, размер 16px weight 350. Подчеркивание только по hover.
3. **Signal Blue Text Link:**
   - Цвет `#0071e3`, weight 350, без подчеркивания в покое, опционально подчеркивание 0.5px `#0071e3`. Единственный элемент с синим текстом.
4. **Pill Tag Chip:**
   - Скругление `9999px`, рамка `0.5px solid #0071e3`, текст `#0071e3`, паддинг `2px 10px`, фон прозрачный.
5. **Rounded Card:**
   - Фон `#fdfdfd`, скругление `54px`, рамка `0.5px solid rgba(0, 0, 0, 0.06)`, паддинг `69px`. Никаких теней.
6. **Floating CTA Pill:**
   - Скругление `26px`, полупрозрачный фон `rgba(12, 13, 15, 0.05)`, текст `#020201` weight 400 (13px), иконка-глиф `#0071e3` слева.
7. **Dark Band Footer:**
   - Полноэкранная полоса с фоном `#0f1012`, паддинг 50px сверху и 69px по бокам, белый текст weight 350.

---

## 6. Принцип Zero-Shadow (Отсутствие теней)

- В интерфейсе **полностью исключены `box-shadow` и размытые тени**.
- Глубина и слои достигаются исключительно за счет:
  1. Разницы светлых тонов (`#fdfdfd` карточки поверх `#f2f2f4` канваса).
  2. Сверхтонких волосяных рамок (`0.5px solid rgba(0, 0, 0, 0.06)`).

---

## 7. Правила Do & Don't

### ✅ ОБЯЗАТЕЛЬНО (Do):
- Использовать начертание weight 350 как базовое для всех текстов.
- Все карточки оформлять со скруглением `54px`, а теги — `9999px`.
- Сохранять щедрый вертикальный интервал 90–100px между логическими блоками.
- Текст на светлом фоне — `#0f1012`, на темном футере — `#fdfdfd`.
- Выравнивать многострочный текст строго по левому краю (без центрирования параграфов).
- Трекинг `-0.02em` на всей типографике.

### ❌ ЗАПРЕЩЕНО (Don't):
- **Никаких теней (drop shadows):** глубина передается сменой оттенков белого и тонкими рамками 0.5px.
- **Никаких сплошных синих заливок:** `#0071e3` используется только для рамок, иконок и цвета текста ссылок.
- **Запрещен вес шрифта выше 400:** semibold/bold нарушают концепцию "whisper-weight".
- **Никаких декоративных фоновых градиентов или цветных пятен:** фон монохромный и чистый.
- **Не превышать ширину 1200px для контентных блоков.**
