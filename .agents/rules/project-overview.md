# 1. Обзор проекта и общие ограничения (project-overview.md)

## Назначение
Высоконагруженный SaaS-сервис конвертации документов и изображений с веб-интерфейсом, личным кабинетом пользователя, закрытой административной панелью, REST API, конвейером конвертации/OCR и системой подписок.

- **Рабочее наименование / домен:** `doc-converter`, доменная зона `.ua`.
- **Этапы реализации:**
  - **Этап 1 (актуальный):** Публичный сайт, личный кабинет, админ-панель (роли, TOTP), REST API (с ключами владельца), конвейер конвертации и OCR, биллинг и подписки (Stripe), хранилище результатов с контролем TTL, мультиязычность.
  - **Этап 2:** Telegram-бот со строгой привязкой к квотам аккаунта (не входит в объем приемки первого этапа).

## Ключевые ограничения юрисдикции и приватности
1. **Строго регион ЕС:** Все вычислительные мощности (воркеры, API, Next.js), базы данных (PostgreSQL, Redis), хранилище объектов (Amazon S3), временные диски и секреты размещаются исключительно в юрисдикции ЕС.
2. **Изоляция от внешних сервисов:** Документы пользователей **никогда** не передаются сторонним сервисам (Stripe, SES, сторонним AI/OCR API). Вся обработка, конвертация, OCR и антивирусная проверка выполняются на собственных мощностях.
3. **Контроль срока жизни (TTL):** Результаты конвертации и временные файлы имеют жесткий срок хранения, по истечении которого гарантированно удаляются служебными процессами очистки.
