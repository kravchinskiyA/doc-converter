# Оформление SaaS-конвертера (Дизайн-система Augen Pro)

**Дата утверждения:** 2 ноября 2026 г.  
**Статус:** Утверждено. Визуальный код базируется на спецификации **Augen Pro** («Apple keynote on surgical white»).

Полное правило для агентов зафиксировано в [.agents/rules/design-system.md](../.agents/rules/design-system.md).

---

## 1. Концепция и эстетика

Стиль проекта — стерильный, невесомый интерфейс потребительского Hi-Tech бренда. Монохромный белый/серый объем, полное отсутствие тяжелых теней (zero-shadows), деликатная ультратонкая типографика (weight 350) и строгий учет цвета — единственный акцентный цвет **Signal Blue** (`#0071e3`) используется только для контуров, иконок и текста ссылок, но никогда как сплошная заливка кнопок.

---

## 2. Цветовая палитра и токены

| Название токена | Значение HEX | Применение |
| :--- | :--- | :--- |
| `color-off-black` | `#0f1012` | Основной текст интерфейса, фон темного футера, иконки на светлом фоне. |
| `color-pure-black`| `#020201` | Вторичный текст, иконки максимального контраста. |
| `color-off-white` | `#f2f2f4` | Фоновый холст страницы (Page Canvas), контрастные подложки секций. |
| `color-pure-white`| `#fdfdfd` | Поверхности карточек, инпуты, плавающее меню навигации. |
| `color-steel-gray`| `#5e5e5e` | Вторичный текст, описания, неактивные подписи (контрастность AA 6.4:1). |

## 3. Типографика

* **Гарнитура:** `PP Neue Montreal` (альтернативы: `Inter` начертания 300/400, `Söhne`, `General Sans`).
* **Основной вес:** **350 (Book)** для всех заголовков и основного текста. Иерархия достигается размером кегля, а не жирностью.
* **Вторичный вес:** **400 (Regular)** исключительно для мелких служебных лейблов (10-13px).
* **Line-height:** 1.20.
* **Letter-spacing:** `-0.02em` (плотный инженерный трекинг на всех размерах).

### Шкала размеров
- **Heading:** 27px (LH: 32.4px, LS: -0.54px)
- **Subheading:** 18px (LH: 21.6px, LS: -0.36px)
- **Body:** 16px (LH: 19.2px, LS: -0.32px)
- **Caption / Meta:** 10px – 13px (LH: 12–15px, LS: -0.2px)

---

## 4. Сетка, отступы и радиусы скругления

* **Максимальная ширина страницы:** 1200px (центрирование по горизонтали).
* **Вертикальный шаг между секциями:** 90px – 100px.
* **Внутренний отступ карточек:** 69px.
* **Радиусы скругления (Border Radius):**
  - Кнопки: `26px`
  - Навигационные плашки: `10px`
  - Большие контентные карточки: `54px` (фирменный мягкий силуэт)
  - Теги, пилюли, бейджи статусов: `9999px`
  - Тонкие рамки: `0.5px` (hairline)

---

## 5. Ключевые компоненты

1. **Floating Pill Navigation Bar:** плавающее верхнее меню со скруглением 10px, фон `#fdfdfd`, отступ сверху 34px.
2. **Rounded Card (54px):** контентный контейнер с белым фоном `#fdfdfd`, тонкой границей `0.5px solid rgba(0,0,0,0.06)` и паддингом 69px без теней.
3. **Pill Tag Chip:** чип категории/формата с полным скруглением `9999px`, границей `0.5px solid #0071e3` и текстом цвета Signal Blue.
4. **Floating CTA Pill:** кнопка основного действия со скруглением `26px`, полупрозрачной подложкой `rgba(12,13,15,0.05)`, темным текстом `#020201` (weight 400) и синей глиф-иконкой.
5. **Dark Band Footer:** полноэкранный темный блок `#0f1012` с центрированным светлым текстом `#fdfdfd`.

---

## 6. Принцип Zero-Shadow (Без теней)

В интерфейсе исключены тени (`box-shadow`). Любое разделение планов и глубина передаются исключительно:
1. Контрастом между холстом `#f2f2f4` и приподнятыми панелями `#fdfdfd`.
2. Тончайшими hairline-рамками `0.5px solid rgba(0, 0, 0, 0.06)` или акцентными `#0071e3`.
